# Book Haven E-Commerce

A responsive bookstore e-commerce website developed using HTML, CSS, and JavaScript.

## Features

* Responsive design for desktop and mobile devices
* Book catalog browsing
* Shopping cart functionality
* Dark mode support
* User authentication pages
* Order tracking page
* Modern and user-friendly interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
